## 安装与更新

- CRX：提供由固定私钥签名的 CRX3 包，是否允许安装取决于浏览器及管理策略。普通 Windows/macOS Chrome 不支持直接安装任意站外 CRX。
- ZIP：下载 `auto-dati-v*.zip`，解压到固定目录，在扩展管理页开启开发者模式并“加载已解压的扩展”。后续更新覆盖同一目录，再点击“重新加载”。
- 更新入口：扩展设置 → 关于与更新，或工具栏快捷面板。检查更新后跳转 GitHub Releases，由用户下载、确认安装。
- 切换不同扩展 ID 前，先导出配置和统计，再导入新安装。Release ZIP 与 CRX 使用同一个签名公钥；源码开发版本使用已有开发 ID。

## 本次功能
