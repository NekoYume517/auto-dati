按功能配置

规则决定识别哪里、点击哪里；自动化决定何时请求、填入和翻页。

三步开始

  1. 1
    填写 API

    在「模型 API」中选择格式、填入 Base URL 与密钥，点「测试连接」确认可用。

  2. 2
    选择模式

    自动答题适合批量刷题；弹窗模式适合逐题确认。两者可同时开启。

  3. 3
    回到网页

    打开题目页面，用 AltQ 框选题目，或让检测器自动识别。
